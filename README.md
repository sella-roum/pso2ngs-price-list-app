# 商品価格一覧アプリケーション

## 概要

このアプリケーションは、商品の価格情報を管理し、表示するためのツールです。最新の価格情報を取得し、様々な条件でフィルタリングや並べ替えを行うことができます。

## 主要機能

1. 商品価格の一覧表示
2. 最新データの取得
3. カテゴリ、商品名、グループ名での検索
4. 価格範囲、更新日での絞り込み
5. 各列でのソート機能
6. ページネーション（ページジャンプ機能付き）
7. CSVダウンロード機能
8. 商品詳細情報の表示（ポップアップ）
9. 価格変動のグラフ表示
10. サマリー情報の表示

## ファイル構造

- `app/`
  - `page.tsx`: メインページコンポーネント
  - `actions.ts`: サーバーアクション（データ取得など）
- `components/`
  - `ProductPriceRecord.tsx`: メインの商品価格一覧コンポーネント
  - `ProductDialog.tsx`: 商品詳細ダイアログコンポーネント
  - `ShipPopover.tsx`: 船舶価格情報ポップオーバーコンポーネント
  - `SummaryTab.tsx`: サマリー情報タブコンポーネント
- `types/`
  - `product.ts`: 商品データの型定義
- `utils/`
  - `formatters.ts`: 日付や価格のフォーマット関数

## 使用技術

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- shadcn/ui コンポーネントライブラリ
- Supabase (バックエンド)

## セットアップ

1. リポジトリをクローンします。
2. `npm install` を実行して依存関係をインストールします。
3. `.env.local` ファイルを作成し、Supabaseの接続情報を設定します。
4. `npm run dev` を実行して開発サーバーを起動します。
